# 🦈 Pet Shark: Free 3D Shark Live Wallpaper & Simulator

**Official Website:** [https://petshark.app](https://petshark.app)  
**Download for Android:** [Get it on Google Play](https://play.google.com/store/apps/details?id=com.petshark.livewallpaper)

**Pet Shark** is a real-time 3D shark live wallpaper, virtual pet aquarium, and predator simulator for Android built with **Three.js** and **Kotlin**.

---

## ✨ Key Features

* **Two Modes:** System live wallpaper or full-screen 3D desk aquarium.
* **Reactive AI:** Real-time predator/prey behavior without pre-rendered loops.
* **Feeding & Sharks:** Double-tap to feed; choose between a Great White or Hammerhead.
* **Smart Performance:** Day/night clock sync, battery-saving FPS options (45/60/120), and zero ads/tracking.

---

## 📱 Requirements & Pricing

* **OS:** Android 8.0+ (~9 MB)
* **Pricing:** Free tier with optional one-time unlock for unlimited throws.
